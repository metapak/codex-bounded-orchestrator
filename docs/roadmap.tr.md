# Yol haritası

Bu yol haritası yönü gösterir; sürüm sözü değildir. Öncelikler, doğrulanan Codex davranışına ve topluluk geri bildirimlerine göre değişebilir.

- [x] v0.2.0: açık rol kaydı, sınırlı sözleşmeler, candidate bütünlük aracı, güvenli cross-platform installer ve public dokümantasyon.
- [x] v0.3.0: yalnız metadata tutan yerel görev ledger'ı ile isteğe bağlı UI tasarımı ve güvenlik review uzmanlık paketleri.
- [ ] Codex istemcisi, ürün yüzeyi ve platform bazında yeniden üretilebilir runtime uyumluluk raporları toplamak.
- [ ] Temsilî mevcut proje config'leriyle güvenli birleştirme için validation fixture'ları eklemek.
- [ ] Kaynak içerik yerine hash ve metadata saklamayı sürdürerek candidate özetlerini geliştirmek.
- [ ] İzinleri, rol sınırları ve runtime davranışı dürüstçe belgelenip test edilebildikten sonra diğer kodlama agent'ları için isteğe bağlı bir adapter değerlendirmek.
- [ ] Kapsam başına tek writer, bağımsız review ve sonlu döngü sınırlarını koruyan ek owner/yönlendirme preset'lerini değerlendirmek.

Yeni bir yol haritası maddesini somut kullanım senaryosu, gözlemlenebilir kabul kriterleri ve izin veya güvenlik sınırlarına etkisiyle birlikte feature request olarak öner.
