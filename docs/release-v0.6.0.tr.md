# v0.6.0 sürüm notları

- Yalnız gözlenen kullanım kaydı farklarını kullanan salt okunur Codex token/model raporu eklendi.
- Dengeli varsayılanı değiştirmeden, yalnız GPT modellerinden oluşan isteğe bağlı `quota-saver` profili eklendi.
- Açıkça çalıştırılan, kabuk kullanmayan yerel değerlendirme ve isteğe bağlı ledger kapısı eklendi.
- Ledger verileri sabit deneme/olay geçmişi, kesinti durumları, tek sınırlı yeniden deneme, türetilen durum ve sorumluya geri yönlendirme bilgisiyle kayıpsız güncellenir.

Kullanım raporu kota yüzdesi, fiyat veya eksiksizlik iddiasında bulunmaz. Yerel değerlendirme açıkça çalıştırılıp görev için seçilene kadar kapalıdır.
